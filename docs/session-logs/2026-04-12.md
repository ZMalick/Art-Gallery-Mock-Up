### 6. Nav dropdown fixes
- **Narrow-desktop breakpoint** (1024–1200px): added a new media query in `css/styles.css` that hides the nav slogan, tightens link padding, and shrinks font size so the Artwork dropdown doesn't crowd the other links.
- **Dropdown alignment**: added `display: inline-flex`, `align-items: center`, `white-space: nowrap`, and replaced the chevron's `margin-bottom` hack with a `translateY` inside its `transform` so the `<button>` toggle lines up with the `<a>` siblings.
- **Hover-gap bridge**: moved the dropdown's gap from `top: calc(100% + 0.65rem)` to `top: 100%; margin-top: 0.65rem;` and added an invisible `.dropdown::before` bridge that spans the visual gap so the cursor can reach the panel without closing it.
- **Mobile-panel bug (the real fix)**: `js/main.js:732` was attaching `closeMenu` to every `.nav-link` in the mobile slide-out panel. The Artwork button has both `dropdown-toggle` and `nav-link` classes, so clicking it opened the sub-menu and immediately slammed the whole panel shut. Added a guard:
  ```js
  if (link.classList.contains('dropdown-toggle')) return;
  ```
  Now Artwork expands Paintings/Sculptures/Sketches in place, and clicking an actual sub-item still closes the panel and navigates.
